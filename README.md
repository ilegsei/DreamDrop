# DreamDrop

Приложение Dreamlaser для файлов проектов: загрузка и скачивание больших файлов
с прогрессом, скоростью и докачкой. Для Windows и macOS. Вход — по учётной записи,
которую выдаёт администратор Dreamlaser.

## Скачать

**[Последняя версия →](https://github.com/ilegsei/DreamDrop/releases/latest)**

| Система | Файл |
|---|---|
| Windows 10 и 11 | `DreamDrop_…_x64-setup.exe` |
| macOS 11 и новее, Mac с процессором Apple (M1 и новее) | `DreamDrop_…_aarch64.dmg` |

## Установка

**Windows.** Запустите `…_x64-setup.exe`. Если появится «Windows защитила ваш компьютер» —
«Подробнее» → «Выполнить в любом случае».

**Mac.** Откройте `.dmg` и перетащите DreamDrop в «Программы». Первый запуск:

- macOS 15 и новее: откройте DreamDrop → «Готово» → Системные настройки →
  Конфиденциальность и безопасность → внизу «Всё равно открыть»;
- macOS 14: правый клик по DreamDrop в «Программах» → «Открыть» → «Открыть».

Подробно — в файле «Как открыть» внутри `.dmg`.

## Обновления

DreamDrop сам проверяет новые версии (при запуске и раз в несколько часов) и предлагает
«Обновить» — повторять установку не нужно. Версию 0.6.0 нужно один раз заменить вручную.

## Вопросы

Если что-то не получается — пришлите администратору скриншот того, что пишет система.
